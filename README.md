📚 BookVault – Library Management System

A Core Java console-based Library Management System for managing book records efficiently.

🚀 Features

Add new books

Update book details

Delete books

Display all books

Book ID, title, and author management

Menu-driven console interface


🛠️ Technologies Used

Java

OOP Concepts

Encapsulation

Constructors

Arrays

CRUD Operations

Scanner


📂 Project Structure

BookVault
└── src
    └── libraryManagementProject
        ├── Book.java
        ├── Library.java
        └── LibraryManagement.java

▶️ How to Run

1. Clone the repository.


2. Open the project in Eclipse or any Java IDE.


3. Run LibraryManagement.java.


4. Choose the required option from the menu.



📌 Operations

1. Add a Book
2. Update Book
3. Delete Book
4. Display All Books
5. Exit
